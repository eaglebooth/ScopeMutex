# Mechanism and originality scope

ScopeMutex is a bounded semantic mutual-exclusion allocator. A single claim call
judges immutable brief scope and complete current held-work overlap, then code
acquires a round-scoped right. The holder-only consumer records one hand-in digest.
Explicit coordinator end-round cancels pending rights; a new epoch requires fresh
claims. It does not use clause partitioning, ballots, adopted rulebooks or escrow.

Shared sender/hash/independent-validator/evidence discipline is not a copied
application architecture. This is not a claim of global novelty or acceptance.
The epoch revision changes liveness/authority expressly; it does not claim to fix
wall-clock expiry or hide the historical failure.
